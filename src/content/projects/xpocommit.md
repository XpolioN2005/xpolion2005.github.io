## Overview

XpoCommit AI is a VS Code extension that generates Git commit messages from workspace changes using Gemini and integrates them directly into the Source Control workflow.

I developed the extension end-to-end, integrating Git change detection, Gemini API communication, and VS Code's Source Control API to generate and insert commit messages directly into the commit field. It also includes configurable file exclusions and secure API key storage through VS Code's secret storage.
