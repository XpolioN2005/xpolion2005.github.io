## Overview

Zion is a cybersecurity platform designed to detect, analyze, and respond to simulated cyber attacks. It combines machine learning-based anomaly detection with rule-based threat analysis and automated mitigation.

I focused on developing the attack simulation systems used to generate and reproduce different security scenarios for testing the platform's detection and response pipeline. I also developed the API integration layer, connecting the system's components and handling the flow of attack data and security events between the backend and frontend.

My work connected the simulated attacks with the platform's detection and monitoring pipeline, allowing security scenarios to move from attack generation through API communication and analysis.
